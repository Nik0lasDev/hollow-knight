# Ruínas do Crepúsculo — protótipo

Protótipo 2D de ação e plataforma feito com HTML5 Canvas e JavaScript puro, inspirado no ritmo de combate de metroidvanias como Hollow Knight. O jogo usa personagens e visuais originais simples, sem depender de bibliotecas ou arquivos externos.

## Como jogar
- Abra `index.html` em um navegador moderno ou publique o repositório com GitHub Pages.
- **Mover:** A/D ou setas; no celular, use os controles na tela.
- **Pular:** Espaço, W ou seta para cima; botão **PULAR** no celular.
- **Atacar:** J ou Z; clique/t toque no cenário ou botão **GOLPE**.
- **Esquivar:** Shift ou K; botão **DASH** no celular.

## Sistemas incluídos
- 5 pontos de vida, invulnerabilidade temporária ao receber dano e reinício após derrota.
- Ataque corpo a corpo direcional com recarga curta e empurrão nos inimigos.
- Pulo, gravidade, plataformas e esquiva rápida.
- Três tipos de inimigos: rastejante, saltador e brutamontes, com vida e comportamento diferentes.
- Essência por derrotar inimigos, contador de derrotas, cenário com câmera lateral e controles responsivos para toque.

## Escopo
Esta é uma base jogável para evoluir: ainda não inclui mapa conectado, salvamento, chefes, habilidades desbloqueáveis ou arte final.
